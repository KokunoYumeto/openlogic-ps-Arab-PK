# په پاکستانۍ پښتو کښې اوپن لاجک

دا د [اوپن لاجک پروژې](https://openlogicproject.org/) خپلواکه پښتو ژباړه ده. متن په عربي ليکدود کښې دے؛ د پاکستان پښتو املا او علمي نثر ته لومړيتوب ورکول شوے دے. افغان پښتو سرچينې چې کارول شوې دي، يوازې د سيمه‌ييزې پرتله‌ييزې مرجع په توګه په شواهدو کښې په ښکاره نومول شوې دي.

**د کار حالت: له ۷۲۲ سرچينو څخه ۵۸۹ واحدونه ژباړل شوي او جوړښتي کتنه ئې تېره کړې ده.** اوسنے لوستونکی [۴۲۰ مخيز PDF](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.pdf) او د هغه [بدلېدونکے EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.epub) دے؛ دواړه ۳۱ څپرکي او لومړي ۳۲۱ واحدونه لري. ورپسې ۲۶۸ واحدونه د سمون وړ منل شوې مسودې دي؛ د دويمې درجې او ګڼ‌ارزښتي منطق، عادي مودالي منطق، زماني او معرفتي منطق، شهودي منطق، مادي او کلک شرطونه، او د واقعيت خلاف شرطونو بشپړه کروي معنٰی پوهنه او د مقدم د پياوړي کولو، انتقاليت او نقيض عکس حدود رانغاړي. د سټ تيورۍ د برخې او د تکراري تصور بشپړ څپرکے هم منل شوي دي؛ د غړو له مخې برابري، د رسل تناقض، پريديکاتيف او امپريديکاتيف، تجمعي پړاوونه، بنسټيز غير سټ غړي او د فرېګه ضميمه پکښې دي. د راتلونکي څپرکي چلوونکے، د پړاوونو مفصل اصول، بېلونه، اتحاد او جوړې هم منل شوي دي؛ د وروستي پړاو نۀ شتون په ښکاره اضافه شوے اصل دے. بشپړ زرمېلو څپرکے اوس د فرعي سټونو سټونه، نامتناهيت، د Zminus عين اصلونه، د طبيعي عددونو بديل تمثيلونه او د بندښت/تقاطع ضميمه هم لري. OLSTH-003 د هر شاهد د تالي ادعا ساتي او د اضافي فرض حدود څرګندوي؛ د بشپړ مقابل ماډل يا استقلال ادعا نۀ کوي. د شهودي سرچينه‌يي ثبوتونو پاتې تشې او د کروي سيمو د نثري بيانونو څرګند حدود ثبت دي. پاتې ۱۳۳ واحدونه لا منل شوې ژباړې ته اړ دي؛ OLP-0589 منل شوے دے؛ OLP-0590 کتل شوې خو لا نۀ منل شوې مسوده لري، او OLP-0591 بل نۀ‌ژباړل شوے واحد دے. دا لا بشپړ کتاب نۀ دے او د انساني ژبپوه يا رياضيپوه د تصويب ادعا نۀ لري.

خپور شوے لوستونکی د بنسټونو، سټونو او اړيکو، تابعو، د سټونو د اندازې، قضيې او لومړۍ درجې منطق، د ثبوت د څلورو نظامونو، بشپړتيا، د مدل تيورۍ، بازګشتي تابعو، محاسبه کېدنې، د ټيورينګ ماشينونو، د نحو حسابي کولو او د ناتکميلۍ قضيو برخې لري. بېلګې، تمرينونه، فارمولونه، جدولونه، ثبوتي ونې، تابلوګانې او شکلونه د اصلي سرچينې له جوړښت سره سم ساتل شوي دي. د اړينو سرچينه‌يي سمونونو او مبهمو نښو يادښتونه د پښتو متن ترڅنګ راغلي دي.

د اصلي سرچينې کره نسخه `9620cc73f9c8e0ad003c514a5d3748f29611c4c0` ده. د هغې ټول ۷۲۲ محتوايي فايلونه له ثبت شويو SHA-256 ارزښتونو سره کتل شوي دي. اتومات کتنه د اصلي فايلونو هشونه، د پاراګرافونو برابرون، چاپېريالونه، فارمولونه، اصطلاحي نښې، حوالې، يونيکوډ او پاتې عادي انګرېزي څېړي. معنايي کتنه د سرچينې او ژباړې د استدلال جهت، شرطونه، کمیت ټاکونکي او د ثبوت اړوندې بېلګې هم پرتله کوي. د پخوانۍ v0.7.0 د PDF ټول ۴۲۰ مخونه په انځوريز عمومي کتنه کښې وکتل شول؛ د v0.7.1 د سمون اړوند مخونه په بشپړ انځور کښې وکتل شول. د EPUB ۵۶ پراخې او د لوستونکي د پردې بېلګې په اتومات ډول وازمېيل شوې، او د نويو څپرکو ۱۴ بېلګې په سترګو وکتل شوې. EPUBCheck 5.4.0 هېڅ پيغام نۀ دے ورکړے. دا کتنې د انسان تصويب يا د هرې ژبنۍ تېروتنې نشتون نۀ ثابتوي.

اصلي انګرېزي تبصرې او پېژندونه د جوړښت د شواهدو دپاره پاتې دي. د اصلي فارمول دننه شخصي نوم `Ruth` يو مستند استثنا ده. د فارمولونو نثري متن پښتو دے. د `psOblique` نښه د پښتو لازمه نحوي بڼه جوړوي، خو د اصلي اصطلاح نښه او کلي ساتي. د v0.7.1 سرچينو ZIP د ۴۰۵ منل شويو مسودو فايلونه لري، خو لوستونکی لومړي ۳۲۱ واحدونه رانغاړي؛ `OLP-0582–0589` منل شوې مسودې لري؛ `OLP-0590` کتل شوې خو لا نۀ منل شوې مسوده لري؛ `OLP-0591` بل نۀ‌ژباړل شوے واحد دے.

## په Windows کښې بياجوړول

Python 3، XeLaTeX له `fontspec`، `amsmath/amsthm`، `bidi`، TikZ، `natbib`، `hyperref` او Amiri فونټ ته اړتيا ده. د همدې زېرمتون له ريښې څخه دا حکمونه وچلوئ:

```powershell
python tools/build_cumulative_reader.py --through-unit 321 --preamble ./tools/cumulative-reader-preamble-v070.tex --build-dir ./build/reader-v071
./tools/guard_tex.ps1 -Passes 3 -BuildDirectory ./build/reader-v071 -DocumentBases reader
python tools/check_translation.py
```

د PDF پايله `build/reader-v071/reader.pdf` ده. د نېغ خپاره شوي LaTeX متن د کره PDF د بياجوړولو دپاره يې `releases/reader.tex` ته کاپي او له هماغې لارې درې خوندي XeLaTeX پړاوونه وچلوئ:

```powershell
Copy-Item ./releases/02-openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.1.tex ./releases/reader.tex
./tools/guard_tex.ps1 -Passes 3 -BuildDirectory ./releases -DocumentBases reader
```

`guard_tex.ps1` د `Global\InterlanguageTeXSlotV1` ماشين‌سراسري قلف اخلي او د TeX د ټولو پړاوونو او لاګ کتنې تر پاې پورې ئې ساتي. د EPUB د ۳۱ شکلونو فهرست له همدې سمونې وړ سرچينو بيا جوړېږي:

```powershell
python tools/derive_cumulative_epub_figures.py --output ./build/v071-figures.json
python tools/render_cumulative_epub_figures.py --phase prepare --expected-figures 31 --inventory ./build/v071-figures.json --build-dir ./build/epub-v071-figures
$figureBases = 1..31 | ForEach-Object { 'figure-{0:D3}' -f $_ }
./tools/guard_tex.ps1 -Passes 1 -BuildDirectory ./build/epub-v071-figures -DocumentBases $figureBases
python tools/render_cumulative_epub_figures.py --phase convert --expected-figures 31 --inventory ./build/v071-figures.json --build-dir ./build/epub-v071-figures --output-dir ./build/epub-v071-svg
python tools/build_cumulative_epub.py --through-unit 321 --edition-version 0.7.1 --reference-map ./evidence/V071_EPUB_REFERENCE_MAP.json --build-dir ./build/epub-v071 --figures-dir ./build/epub-v071-svg
python tools/validate_cumulative_epub.py --epub ./build/epub-v071/openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.1.epub --build-record ./build/epub-v071/build-epub.json --alignment ./evidence/ALIGNMENT.jsonl --reference-map ./evidence/V071_EPUB_REFERENCE_MAP.json --output ./build/epub-v071/validation.json
```

د [مخونو کره لړ](evidence/V071_READER_OCCURRENCE_PAGES.json) د PDF له دوه يو شان AUX فايلونو جوړ شوے دے. د سرچينو ZIP کښې د EPUB د عددونو [منل شوې نقشه](evidence/V071_EPUB_REFERENCE_MAP.json)، جوړوونکي او د شکلونو سرچينې شته. د خپرونې د فايلونو هشونه د هغې له SHA-256 لړ سره پرتله کړئ.

## د AI کار، منسوبول او جواز

د دې نسخې پښتو ژباړه، د فارمولونو ترڅنګ توضيحي سمونونه او تر `OLP-0311` پورې متن‌کتنه **OpenAI Codex — GPT-5.6 Sol، Ultra هڅه** ترسره کړې ده. د B057 د شواهدو وروستۍ بياجوړونه، د لاسرسي پښتو معلومات، او د `OLP-0312` تر `OLP-0541` ژباړه، سرچينه‌يي سمونونه او کتنه **OpenAI Codex — GPT-6 Sol، Ultra هڅه** برابر کړي دي. په `OLP-0177` کښې د پريديکاتيف او امپريديکاتيف د دوو نومونو سمون هم **OpenAI Codex — GPT-6 Sol، Ultra هڅه** کړے دے. د `OLP-0557–0588` منل شوې مسودې هم **OpenAI Codex — GPT-6 Sol، Ultra هڅه** برابرې کړې دي. دا کار د انساني ژباړې يا تخصصي تصويب په توګه نۀ وړاندې کېږي. د `OLP-0177` د نومونو له سمون وروسته د اوسني سرچينه‌يي هش د رښتيني جوړ شوي متن کتنه ۱۰۵ واحدونه رانغاړي؛ خپور شوے ۳۲۱ واحديز لوستونکی خپله ساتل شوې پخوانۍ نسخه ده. د اصلي اوپن لاجک د ليکوالو او ونډه‌والو نومونه او د برخو ځانګړي جوازونه په `upstream/` کښې ساتل شوي دي؛ له پروژې سره رسمي تړاو يا د هغې تاييد نۀ ادعا کېږي.
