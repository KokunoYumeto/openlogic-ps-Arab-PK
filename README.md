# اوپن لاجک په پاکستانۍ پښتو کښې

[PDF ولولئ](readers/openlogic-ps-Arab-PK-complete.pdf) · [EPUB](readers/openlogic-ps-Arab-PK-complete.epub) · [د لوستونکي لاټېک](releases/openlogic-ps-Arab-PK-complete.tex) · [سمون‌وړ سرچينه](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases/download/v1.0.0/openlogic-ps-Arab-PK-complete-source.zip) · [English](README.en.md)

دا د اوپن لاجک د ټولو ۷۲۲ سرچينه‌يي واحدونو سمه شوې، په مصنوعي ځيرکتيا ژباړل شوې بڼه ده۔ متن په عربي ليکدود کښې د پاکستانۍ پښتو کارونه راخلي۔ موضوعات ئې سټونه، اړيکې او تابعې، د ثبوت لارې، د قضيو او لومړۍ درجې منطق، مدل تيوري، محاسبه کېدنه، د ټيورينګ ماشينونه، ناتکميلي، د دويمې درجې او ناکلاسيک منطقونه، سټ نظريه، ثبوت تيوري، لامبدا حساب او د منطق او سټ نظريې تاريخ دے۔ تعريفونه، بېلګې، تمرينونه، ثبوتونه، شکلونه او سرچينې ورسره دي۔

د اصل ليکوالان د [اوپن لاجک پروژې ونډه‌وال](https://openlogicproject.org/people/) دي۔ ژباړه [د اصل 9620cc7 نسخه](https://github.com/OpenLogicProject/OpenLogic/tree/9620cc73f9c8e0ad003c514a5d3748f29611c4c0) راخلي۔ د متن جواز [Creative Commons Attribution 4.0 International](LICENSE.md) دے۔ د بېلو اجزاوو جوازونه په سمون‌وړه سرچينه کښې راغلي دي۔ په لوستونکي کښې رياضيکي شکلونه او ژوندليکونه شته۔ د عکسونو نسبت او د هغو د جوازونو تړوني په سرچينه کښې خوندي دي۔

پښتو ژباړه او سمونونه اوپن اې‌آی کوډېکس جوړ کړي دي۔ GPT-5.6 Sol د ۱ تر ۳۱۱، GPT-6 Sol د ۳۱۲ تر ۶۰۸ او GPT-6.1 Sol د ۶۰۹ تر ۷۲۲ واحدونو ژباړه کړې ده۔ GPT-6.1 Sol پخوانی متن هم کتلے او سم کړے دے۔ په هر پړاو کښې Ultra استدلال کارول شوے دے۔

په سمون‌وړه سرچينه کښې جلا پښتو واحدونه، د ټول کتاب لاټېک، د جوړولو وسيلې، کتابښود او د شکلونو فايلونه شته۔ د PDF او EPUB د جوړولو لارښوونې د ZIP په دننه کښې دي۔ د `bussproofs-extra` بېل جواز [LPPL 1.3 يا وروستۍ بڼه](https://www.latex-project.org/lppl/lppl-1-3c/) دے۔ د فونټونو جوازونه په [انګرېزي لارښود](README.en.md) کښې راغلي دي۔
