# B151 — د شهودي منطق او نحو کانوني کتنه

د OLP-0491–0494 لپاره د پېښور پښتو اکاډمۍ `PK-IQRAM-P1-PROSE` او `PK-IQRAM-P2-SEMANTICS` د پاکستانۍ علمي نثر او معنايي جملې لومړني شاهدان دي؛ `GRAMMAR-P166-SOV` د جملې ترتيب ښيي. د `TERM-INTUITIONISTIC-LOGIC` مخکنۍ «شهودي منطق» او «تعميري» بڼې، د `TERM-NUMBERSETS` «ناطق / غير ناطق / حقيقي / طبيعي عددونه»، او د `TERM-PROP-SYNTAX` «بياني متغير / منطقي نښلوونکے / عطف / فصل / شرطي / نفي / دوه اړخيز شرطي» همغږي ساتل شوې. د افغان `AF-BUKOVSKY-P21-SQRT2-IRRATIONAL-BOUNDS` مخ انځور د OLP-0493 لپاره وکتل شو: هلته د `√2` د غير ناطق والي ثبوت او د ناطق/حقيقي عددونو نثر شته؛ د OpenLogic د دوو ثبوتونو محتوا له منجمدې سرچينې راځي. افغان `AF-NIAZMAN-P37-AXIOMATIC-PROOF` او `AF-NIAZMAN-P18-FORMATION-SEQUENCE` يوازې د ثبوت او نحو سيمه‌ييزه مقايسه ده. د مخونو انځور هشونه په `CANON_PASSAGES.jsonl` کښې دي.

د ريمان د فرضيې، براور او بېشپ نومونه د سرچينې د پېژندنې لپاره په پښتو غږيزه بڼه ساتل شوي؛ عين پاکستانۍ چاپي بڼې ئې په دغو مخونو کښې نۀ دي ثابتې. د OLP-0493 د لومړي ثبوت د حالتونو وېش او د دويم ښکاره شاهد، او د OLP-0494 د لومړنيو/تعريف شويو نښلوونکو توپير سرچينه ټاکي. کانون رياضيکي فورمولونه نۀ بدلوي.
