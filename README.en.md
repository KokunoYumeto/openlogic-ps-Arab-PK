# Open Logic Text in Pashto — Pakistan

[Read the PDF](readers/openlogic-ps-Arab-PK-complete.pdf) · [EPUB](readers/openlogic-ps-Arab-PK-complete.epub) · [Reader LaTeX](releases/openlogic-ps-Arab-PK-complete.tex) · [Editable source ZIP](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases/download/v1.0.0/openlogic-ps-Arab-PK-complete-source.zip) · [پښتو](README.ps-Arab-PK.md)

This corrected, AI-translated edition covers all 722 source units of the Open Logic Text in Pakistani Pashto in Arabic script. It includes sets, relations and functions, proof methods, propositional and first-order logic, model theory, computability, Turing machines, incompleteness, second-order and nonclassical logics, set theory, proof theory, lambda calculus, and the history of logic and set theory. It includes definitions, examples, exercises, proofs, diagrams and a bibliography.

The original authors are the [Open Logic Project contributors](https://openlogicproject.org/people/). The translation follows [upstream revision 9620cc7](https://github.com/OpenLogicProject/OpenLogic/tree/9620cc73f9c8e0ad003c514a5d3748f29611c4c0). The text uses [Creative Commons Attribution 4.0 International](LICENSE.md), with component notices preserved in the source package. The reader includes mathematical diagrams and biographical text. Photograph provenance remains in the source package, with links to the credited images and their separate terms.

OpenAI Codex produced the Pashto translation and corrections. GPT-5.6 Sol produced units 1–311, GPT-6 Sol produced units 312–608, and GPT-6.1 Sol produced units 609–722 and revised earlier material. Each used Ultra reasoning.

The editable package includes the Pashto units, cumulative LaTeX, build tools, bibliography and figure inputs. Use the build guide inside the ZIP to reproduce the PDF and EPUB. The [original package source](https://ctan.org/pkg/bussproofs-extra) is available through CTAN.
