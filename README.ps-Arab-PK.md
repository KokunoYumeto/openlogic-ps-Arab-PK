# په پاکستانۍ پښتو کښې اوپن لاجک

دا د [اوپن لاجک پروژې](https://openlogicproject.org/) خپلواکه پښتو ژباړه ده. متن په عربي ليکدود کښې دے؛ د پاکستان پښتو املا او علمي نثر ته لومړيتوب ورکول شوے دے. افغان پښتو سرچينې چې کارول شوې دي، يوازې د سيمه‌ييزې پرتله‌ييزې مرجع په توګه په شواهدو کښې په ښکاره نومول شوې دي.

**د کار حالت: له ۷۲۲ سرچينو څخه ۳۱۱ واحدونه ژباړل شوي او جوړښتي کتنه ئې تېره کړې ده.** اوسنے خپور شوے لوستونکی [۳۲۶ مخيز PDF](readers/openlogic-ps-Arab-PK-cumulative-through-computability.pdf) او د هغه [بدلېدونکے EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-computability.epub) دے؛ دواړه ۲۵ څپرکي او لومړي ۲۵۵ واحدونه لري. راتلونکي ۵۶ واحدونه د سمون وړ، جوړښتي منل شوې مسودې دي چې د حسابي نحو، په رابنسن حساب Q کښې د تمثيل، د تيوريو د پرېکړه‌وړتيا، د ناتکميلۍ لومړۍ قضيې او تفسيرېدنې تر بحثه رسېږي. پاتې ۴۱۱ واحدونه لا ژباړې ته اړ دي. دا لا بشپړ کتاب نۀ دے او د انساني ژبپوه يا رياضيپوه د تصويب ادعا نۀ لري.

د لوستلو دپاره [اوسنے PDF](readers/openlogic-ps-Arab-PK-cumulative-through-computability.pdf) يا [EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-computability.epub) پرانيزئ. د پخوانيو نسخو [د ثبوت نظامونو او بشپړتيا PDF](readers/openlogic-ps-Arab-PK-proof-systems-completeness.pdf)، [د هغه EPUB](readers/openlogic-ps-Arab-PK-proof-systems-completeness.epub)، [د ثبوت نظامونو PDF](readers/openlogic-ps-Arab-PK-proof-systems.pdf)، [د سټونو، اړيکو او تابعو PDF](readers/openlogic-ps-Arab-PK-sets-relations-functions.pdf)، [د سټونو او اړيکو PDF](readers/openlogic-ps-Arab-PK-sets-relations.pdf) او [د سټونو PDF](readers/openlogic-ps-Arab-PK-sets.pdf) هم ساتل شوي دي. د نسخو بشپړ توکي په [GitHub خپرونو](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases) کښې شته. اوسنۍ خپره شوې نسخه د [Zenodo په دې ثبت](https://doi.org/10.5281/zenodo.22851904) کښې هم شته او د [همدې نسخو له لړۍ](https://doi.org/10.5281/zenodo.22307197) سره تړلې ده. د [ژباړو عمومي لړليک](https://github.com/KokunoYumeto/OpenLogic-translations) ته هم ورشئ. [انګرېزي معلومات](README.en.md) د اضافي مرستې دپاره شته.

د [v0.6.0 GitHub خپرونه](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases/tag/v0.6.0-computability) د لوستلو PDF، ورسره نېغ د ښکته کولو وړ بشپړ يوځای شوے LaTeX متن، د بياجوړولو له اړينو فايلونو سره د سمونې وړ سرچينې ZIP، EPUB، د کتنې شواهد او SHA-256 ارزښتونه لري. د همدې چاپ د لوستلو PDF لومړے راځي، بيا د هغه نېغ LaTeX فايل او ورپسې د سرچينو ZIP. په `ps-Arab-PK/` کښې د پښتو سرچينې د اصلي پروژې د لارو له مخې ساتل کېږي؛ په `upstream/` کښې اصلي انګرېزي بايټونه بدل شوي نۀ دي.

## منځپانګه، شواهد او سمونونه

خپور شوے لوستونکی د بنسټونو، سټونو او اړيکو، تابعو، د سټونو د اندازې، قضيې او لومړۍ درجې منطق، د ثبوت د څلورو نظامونو، بشپړتيا، د مدل تيورۍ، بازګشتي تابعو، محاسبه کېدنې او د ټيورينګ ماشين د ابتدايي څرګندونو برخې لري. بېلګې، تمرينونه، فارمولونه، جدولونه، ثبوتي ونې، تابلوګانې او شکلونه د اصلي سرچينې له جوړښت سره سم ساتل شوي دي. د اړينو سرچينه‌يي سمونونو او مبهمو نښو يادښتونه د پښتو متن ترڅنګ راغلي دي.

د اصلي سرچينې کره نسخه `9620cc73f9c8e0ad003c514a5d3748f29611c4c0` ده. د هغې ټول ۷۲۲ محتوايي فايلونه له ثبت شويو SHA-256 ارزښتونو سره کتل شوي دي. [د سرچينو لړ](evidence/SOURCE_MANIFEST.jsonl) د هر واحد پېژند، لاره او اصلي بايټونه ثبتوي. د پاکستان د پېښور پښتو اکاډمۍ اصلي پښتو نثر، افغان پښتو رياضيکي مواد د پرتله‌ييزو شاهدانو په توګه، او د ګرامر مرجع په [سرچينو](evidence/CANON_SOURCES.jsonl) او [کتل شويو مخونو](evidence/CANON_PASSAGES.jsonl) کښې په دقيقو پېژندونو او هشونو ثبت دي. د هغو اصلي PDF کاپيانې د څېړنې شخصي نسخې دي او دلته بيا نۀ خپرېږي.

د [اصطلاحاتو او ژباړې د انتخابونو د کتنې لارښود](EXPERT_REVIEW.ps-Arab-PK.md) په پښتو کښې د کتنې لاره ښيي. [تفصيلي ماشيني ثبت](evidence/DECISIONS.json)، [بشپړ شاخص](evidence/TRANSLATION_DECISIONS_FULL.md)، [لومړيتوب لرونکې کتنه](evidence/PRIORITY_REVIEW.md)، [د پېښو CSV](evidence/DECISION_OCCURRENCES.csv)، [سکيما](evidence/translation-decision.schema.json) او [د اعتبار رسيد](evidence/TRANSLATION_DECISION_QA.json) هم شته. اوس ۱۶۹ اصطلاحي او ۲۵۲ نورې ستونزمنې پرېکړې، په ټوليز ډول ۴۲۱ پرېکړې او ۱۸٬۸۱۴ کره د سرچينې/ژباړې جوړې پېښې ثبت دي. له دغو پېښو څخه ۱۴٬۸۱۰ په منل شوي لوستونکي کښې کره مخ لري؛ ۴٬۰۰۴ د راتلونکي لوستونکي تر ټيکاوه پورې په ښکاره «pending» پاتې دي. د کارپوهانو راتلونکے نظر د سمون دپاره ګټور دے، خو د کار يا خپرونې شرط نۀ دے.

[د سرچينې د سمونونو پښتو کتنه](EXPERT_REVIEW.ps-Arab-PK.md#د-سرچينې-سمونونه) ۲۴۶ منل شوي سمونونه پېژني؛ [انګرېزي تفصيلي ثبت](SOURCE_CORRECTIONS.md) اضافي دے. د [بېرته اخيستل شويو دوو پخوانيو خبرتياوو ثبت](evidence/SOURCE_AUDIT_RETRACTIONS.jsonl) ښيي چې `OLSIZ-011` او `OLINF-002` فعال سمونونه نۀ دي. کله چې په شته پښتو سرچينو کښې د يوې تخنيکي اصطلاح کره استعمال نۀ وي موندل شوے، غوره شوې بڼه د شواهدو پر بنسټ د سمون وړ موقتي پرېکړه ده، د رسمي معيار دعوه نۀ ده.

## کتنه او د لوستونکي حدود

اتومات کتنه د اصلي فايلونو هشونه، د پاراګرافونو برابرون، چاپېريالونه، فارمولونه، اصطلاحي نښې، حوالې، يونيکوډ او پاتې عادي انګرېزي څېړي. معنايي کتنه د سرچينې او ژباړې د استدلال جهت، شرطونه، کمیت ټاکونکي او د ثبوت اړوندې بېلګې هم پرتله کوي. د لوستونکي PDF ټول ۳۲۶ مخونه او په EPUB کښې د مختلفو پردو ۴۲ بېلګې په رښتيني ښکاره بڼه کتل شوي دي. EPUBCheck 5.4.0 هېڅ پيغام نۀ دے ورکړے. دغه کتنې د انسان د تصويب ځاے نۀ نيسي او د هرې ژبنۍ تېروتنې نشتون نۀ ثابتوي.

اصلي انګرېزي تبصرې او پېژندونه د جوړښت د شواهدو دپاره پاتې دي. د اصلي فارمول دننه شخصي نوم `Ruth` يو مستند استثنا ده. د فارمولونو نثري متن پښتو دے. د `psOblique` نښه د پښتو لازمه نحوي بڼه جوړوي، خو د اصلي اصطلاح نښه او کلي ساتي. د ۳۱۱ مسودو فايلونه په کاري ونې کښې شته؛ راتلونکے واحد `OLP-0312` دے.

## په Windows کښې بياجوړول

Python 3، XeLaTeX له `fontspec`، `amsmath/amsthm`، `bidi`، TikZ، `natbib`، `hyperref` او Amiri فونټ ته اړتيا ده. د همدې زېرمتون له ريښې څخه دا حکمونه وچلوئ:

```powershell
python tools/build_cumulative_reader.py --build-dir ./build/reader-cumulative
./tools/guard_tex.ps1 -Passes 3 -BuildDirectory ./build/reader-cumulative -DocumentBases reader
python tools/check_translation.py
```

د PDF پايله `build/reader-cumulative/reader.pdf` ده. `guard_tex.ps1` د `Global\InterlanguageTeXSlotV1` ماشين‌سراسري قلف د ټاکلي مهلت په دننه کښې اخلي، د TeX د ټولو پړاوونو او سمدستي لاګ کتنې تر پاې پورې ئې ساتي او په پای کښې ئې خوشې کوي. ټاکلے `SOURCE_DATE_EPOCH` د بياجوړونې د يو شان پايلې مرسته کوي.

د EPUB جوړوونکی د شکلونو د دوه‌پړاويزې کړنلارې منل شوې پايله کاروي چې په `tools/render_cumulative_epub_figures.py` کښې ثبت ده:

```powershell
python tools/build_cumulative_epub.py --build-dir ./build/epub-cumulative --figures-dir ./build/epub-cumulative-figures --output ./build/epub-cumulative/openlogic-ps-Arab-PK-cumulative-through-computability.epub
python tools/validate_cumulative_epub.py --epub ./build/epub-cumulative/openlogic-ps-Arab-PK-cumulative-through-computability.epub --build-record ./build/epub-cumulative/build-epub.json --alignment ./evidence/ALIGNMENT.jsonl --reference-map ./evidence/CUMULATIVE_EPUB_REFERENCE_MAP.json --output ./build/epub-cumulative/independent-validation.json
```

[د EPUB د منلو رسيد](evidence/EPUB_DELIVERY_ACCEPTANCE.json) د بياجوړونې، جوړښت، اړيکو او ليديزې کتنې پايلې ثبتوي. [د نېغ LaTeX د اعتبار رسيد](evidence/DIRECT_TEX_VALIDATION.json) د هرې خپرې شوې نسخې درې خوندي پړاوونه او د PDF له عامه هش سره برابري ثبتوي.
