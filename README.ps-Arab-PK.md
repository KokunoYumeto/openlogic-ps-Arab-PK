# په پاکستانۍ پښتو کښې اوپن لاجک

دا د [اوپن لاجک پروژې](https://openlogicproject.org/) خپلواکه پښتو ژباړه ده. متن په عربي ليکدود کښې دے؛ د پاکستان پښتو املا او علمي نثر ته لومړيتوب ورکول شوے دے. افغان پښتو سرچينې چې کارول شوې دي، يوازې د سيمه‌ييزې پرتله‌ييزې مرجع په توګه په شواهدو کښې په ښکاره نومول شوې دي.

**د کار حالت: له ۷۲۲ سرچينو څخه ۳۶۲ واحدونه ژباړل شوي او جوړښتي کتنه ئې تېره کړې ده.** اوسنے لوستونکی [۴۲۰ مخيز PDF](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.pdf) او د هغه [بدلېدونکے EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.epub) دے؛ دواړه ۳۱ څپرکي او لومړي ۳۲۱ واحدونه لري. له بنسټونو څخه تر محاسبه کېدنې، د نحو حسابي کولو او د ګوډل او روسر د ناتکميلۍ قضيو پورې رسېږي. ورپسې ۴۱ واحدونه د سمون وړ منل شوې مسودې دي چې د دويمې درجې منطق او د لامبډا حساب د الفا-بدلون تر برخې پورې رسېږي. پاتې ۳۶۰ واحدونه لا ژباړې ته اړ دي. دا لا بشپړ کتاب نۀ دے او د انساني ژبپوه يا رياضيپوه د تصويب ادعا نۀ لري.

د لوستلو دپاره [اوسنے PDF](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.pdf) يا [EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.epub) پرانيزئ. د تېرې [محاسبه کېدنې PDF](readers/openlogic-ps-Arab-PK-cumulative-through-computability.pdf) او [EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-computability.epub) په ګډون پخوانۍ نسخې هم ساتل شوې دي. د هر چاپ بشپړ توکي په [GitHub خپرونو](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases) کښې شته؛ د [Zenodo د همدې نسخو لړۍ](https://doi.org/10.5281/zenodo.22307197) هم وګورئ. د [ژباړو عمومي لړليک](https://github.com/KokunoYumeto/OpenLogic-translations) ته هم ورشئ. [انګرېزي اضافي معلومات](README.en.md) هم شته.

د [v0.7.0 GitHub خپرونه](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases/tag/v0.7.0-incompleteness) د لوستلو PDF، د هغه نېغ ښکته کېدونکے بشپړ يوځای شوے [LaTeX متن](releases/02-openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.0.tex)، د بياجوړولو له اړينو فايلونو سره د سمونې وړ سرچينو ZIP، EPUB، د کتنې شواهد او SHA-256 ارزښتونه لري. د PDF فايل د لوستلو او کتنې دپاره لومړے راځي؛ ورپسې LaTeX او سرچينو ZIP دي. په `ps-Arab-PK/` کښې پښتو سرچينې د اصلي پروژې له لارو سره سمې دي او په `upstream/` کښې د انګرېزي اصلي بايټونه بدل شوي نۀ دي.

## منځپانګه، شواهد او سمونونه

خپور شوے لوستونکی د بنسټونو، سټونو او اړيکو، تابعو، د سټونو د اندازې، قضيې او لومړۍ درجې منطق، د ثبوت د څلورو نظامونو، بشپړتيا، د مدل تيورۍ، بازګشتي تابعو، محاسبه کېدنې، د ټيورينګ ماشينونو، د نحو حسابي کولو او د ناتکميلۍ قضيو برخې لري. بېلګې، تمرينونه، فارمولونه، جدولونه، ثبوتي ونې، تابلوګانې او شکلونه د اصلي سرچينې له جوړښت سره سم ساتل شوي دي. د اړينو سرچينه‌يي سمونونو او مبهمو نښو يادښتونه د پښتو متن ترڅنګ راغلي دي.

د اصلي سرچينې کره نسخه `9620cc73f9c8e0ad003c514a5d3748f29611c4c0` ده. د هغې ټول ۷۲۲ محتوايي فايلونه له ثبت شويو SHA-256 ارزښتونو سره کتل شوي دي. [د سرچينو لړ](evidence/SOURCE_MANIFEST.jsonl) د هر واحد پېژند، لاره او اصلي بايټونه ثبتوي. د پاکستان د پېښور پښتو اکاډمۍ اصلي پښتو نثر، افغان پښتو رياضيکي مواد د پرتله‌ييزو شاهدانو په توګه، او د ګرامر مرجع په [سرچينو](evidence/CANON_SOURCES.jsonl) او [کتل شويو مخونو](evidence/CANON_PASSAGES.jsonl) کښې په دقيقو پېژندونو او هشونو ثبت دي. د هغو اصلي PDF کاپيانې د څېړنې شخصي نسخې دي او دلته بيا نۀ خپرېږي.

د [اصطلاحاتو او ژباړې د انتخابونو د کتنې لارښود](EXPERT_REVIEW.ps-Arab-PK.md) په پښتو کښې د کتنې لاره ښيي. [تفصيلي ماشيني ثبت](evidence/DECISIONS.json)، [بشپړ شاخص](evidence/TRANSLATION_DECISIONS_FULL.md)، [لومړيتوب لرونکې کتنه](evidence/PRIORITY_REVIEW.md)، [د پېښو CSV](evidence/DECISION_OCCURRENCES.csv)، [سکيما](evidence/translation-decision.schema.json) او [د اعتبار رسيد](evidence/TRANSLATION_DECISION_QA.json) هم شته. اوس ۱۸۷ اصطلاحي او ۲۸۹ نورې ستونزمنې پرېکړې، په ټوليز ډول ۴۷۶ پرېکړې او ۱۹٬۸۹۴ کره د سرچينې/ژباړې جوړې پېښې ثبت دي. له دغو پېښو څخه ۱۸٬۴۵۵ د ۳٬۴۱۴ برخو له کره مخ‌نښو سره په منل شوي لوستونکي کښې ځای لري؛ ۱٬۴۳۹ لا په ښکاره «pending» دي. د يوه خوځېدونکي شکل د مخ‌نښو استثنا په [مخ‌لړ](evidence/READER_OCCURRENCE_PAGES.json) کښې ثبت ده. د کارپوهانو راتلونکے نظر د سمون دپاره ګټور دے، خو د کار يا خپرونې شرط نۀ دے.

[د سرچينې د سمونونو پښتو کتنه](EXPERT_REVIEW.ps-Arab-PK.md#د-سرچينې-سمونونه) ۲۸۳ منل شوي سمونونه پېژني؛ [انګرېزي تفصيلي ثبت](SOURCE_CORRECTIONS.md) اضافي دے. د [بېرته اخيستل شويو څلورو خبرتياوو ثبت](evidence/SOURCE_AUDIT_RETRACTIONS.jsonl) ښيي چې `OLSIZ-011`، `OLINF-002`، `OLSOL-004` او `OLSOL-005` فعال سمونونه نۀ دي؛ د وروستيو دوو د سرچينې د قسمي ليبل او د درې ټکو د مانا کره کتنه ثبت ده. کله چې په شته پښتو سرچينو کښې د يوې تخنيکي اصطلاح کره استعمال نۀ وي موندل شوے، غوره شوې بڼه د شواهدو پر بنسټ د سمون وړ موقتي پرېکړه ده، د رسمي معيار دعوه نۀ ده.

## کتنه او د لوستونکي حدود

اتومات کتنه د اصلي فايلونو هشونه، د پاراګرافونو برابرون، چاپېريالونه، فارمولونه، اصطلاحي نښې، حوالې، يونيکوډ او پاتې عادي انګرېزي څېړي. معنايي کتنه د سرچينې او ژباړې د استدلال جهت، شرطونه، کمیت ټاکونکي او د ثبوت اړوندې بېلګې هم پرتله کوي. د ۴۲۰ مخيز PDF ټول مخونه په انځوريز عمومي کتنه کښې وکتل شول؛ د اړينو مخونو بشپړ انځورونه هم وکتل شول. د EPUB ۵۶ پراخې او د لوستونکي د پردې بېلګې په اتومات ډول وازمېيل شوې، او د نويو څپرکو ۱۴ بېلګې په سترګو وکتل شوې. EPUBCheck 5.4.0 هېڅ پيغام نۀ دے ورکړے. دا کتنې د انسان تصويب يا د هرې ژبنۍ تېروتنې نشتون نۀ ثابتوي.

اصلي انګرېزي تبصرې او پېژندونه د جوړښت د شواهدو دپاره پاتې دي. د اصلي فارمول دننه شخصي نوم `Ruth` يو مستند استثنا ده. د فارمولونو نثري متن پښتو دے. د `psOblique` نښه د پښتو لازمه نحوي بڼه جوړوي، خو د اصلي اصطلاح نښه او کلي ساتي. د ۳۶۲ مسودو فايلونه په کاري ونې کښې شته؛ راتلونکے واحد `OLP-0363` دے.

## په Windows کښې بياجوړول

Python 3، XeLaTeX له `fontspec`، `amsmath/amsthm`، `bidi`، TikZ، `natbib`، `hyperref` او Amiri فونټ ته اړتيا ده. د همدې زېرمتون له ريښې څخه دا حکمونه وچلوئ:

```powershell
python tools/build_cumulative_reader.py --through-unit 321 --preamble ./tools/cumulative-reader-preamble-v070.tex --build-dir ./build/reader-v070
./tools/guard_tex.ps1 -Passes 3 -BuildDirectory ./build/reader-v070 -DocumentBases reader
python tools/check_translation.py
```

د PDF پايله `build/reader-v070/reader.pdf` ده. د نېغ خپاره شوي LaTeX متن د کره PDF د بياجوړولو دپاره يې `releases/reader.tex` ته کاپي او له هماغې لارې درې خوندي XeLaTeX پړاوونه وچلوئ:

```powershell
Copy-Item ./releases/02-openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.0.tex ./releases/reader.tex
./tools/guard_tex.ps1 -Passes 3 -BuildDirectory ./releases -DocumentBases reader
```

`guard_tex.ps1` د `Global\InterlanguageTeXSlotV1` ماشين‌سراسري قلف اخلي او د TeX د ټولو پړاوونو او لاګ کتنې تر پاې پورې ئې ساتي. د EPUB د ۳۱ شکلونو فهرست له همدې سمونې وړ سرچينو بيا جوړېږي:

```powershell
python tools/derive_cumulative_epub_figures.py --output ./build/v070-figures.json
python tools/render_cumulative_epub_figures.py --phase prepare --expected-figures 31 --inventory ./build/v070-figures.json --build-dir ./build/epub-v070-figures
$figureBases = 1..31 | ForEach-Object { 'figure-{0:D3}' -f $_ }
./tools/guard_tex.ps1 -Passes 1 -BuildDirectory ./build/epub-v070-figures -DocumentBases $figureBases
python tools/render_cumulative_epub_figures.py --phase convert --expected-figures 31 --inventory ./build/v070-figures.json --build-dir ./build/epub-v070-figures --output-dir ./build/epub-v070-svg
python tools/build_cumulative_epub.py --through-unit 321 --reference-map ./evidence/V070_EPUB_REFERENCE_MAP.json --build-dir ./build/epub-v070 --figures-dir ./build/epub-v070-svg
python tools/validate_cumulative_epub.py --epub ./build/epub-v070/openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.0.epub --build-record ./build/epub-v070/build-epub.json --alignment ./evidence/ALIGNMENT.jsonl --reference-map ./evidence/V070_EPUB_REFERENCE_MAP.json --output ./build/epub-v070/validation.json
```

د [مخونو کره لړ](evidence/READER_OCCURRENCE_PAGES.json) د PDF له دوه يو شان AUX فايلونو جوړ شوے دے. د سرچينو ZIP کښې د EPUB د عددونو [منل شوې نقشه](evidence/V070_EPUB_REFERENCE_MAP.json)، جوړوونکي او د شکلونو سرچينې شته. د خپرونې د فايلونو هشونه د هغې له SHA-256 لړ سره پرتله کړئ.

## د AI کار، منسوبول او جواز

د دې نسخې پښتو ژباړه، د فارمولونو ترڅنګ توضيحي سمونونه او تر `OLP-0311` پورې متن‌کتنه **OpenAI Codex — GPT-5.6 Sol، Ultra هڅه** ترسره کړې ده. د B057 د شواهدو وروستۍ بياجوړونه، د لاسرسي پښتو معلومات، او د `OLP-0312` تر `OLP-0362` ژباړه، سرچينه‌يي سمونونه او کتنه **OpenAI Codex — GPT-6 Sol، Ultra هڅه** برابر کړي دي. دا کار د انساني ژباړې يا تخصصي تصويب په توګه نۀ وړاندې کېږي. د اصلي اوپن لاجک د ليکوالو او ونډه‌والو نومونه او د برخو ځانګړي جوازونه په `upstream/` کښې ساتل شوي دي؛ له پروژې سره رسمي تړاو يا د هغې تاييد نۀ ادعا کېږي.
