# په پاکستانۍ پښتو کښې اوپن لاجک

دا د [اوپن لاجک پروژې](https://openlogicproject.org/) خپلواکه پښتو ژباړه ده. متن په عربي ليکدود کښې دے؛ د پاکستان پښتو املا او علمي نثر ته لومړيتوب ورکول شوے دے. افغان پښتو سرچينې چې کارول شوې دي، يوازې د سيمه‌ييزې پرتله‌ييزې مرجع په توګه په شواهدو کښې په ښکاره نومول شوې دي.

**د کار حالت: له ۷۲۲ سرچينو څخه ۶۴۸ واحدونه سمون وړ پښتو مسودې لري؛ د GPT-6 Sol د ژباړې او شواهدو خپلواکه بياکتنه روانه ده.** خپور [۴۲۰ مخيز PDF](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.pdf) او [بدلېدونکے EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.epub) لومړي ۳۲۱ واحدونه لري. ورپسې ۳۲۷ واحدونه په سمون وړ سرچينو کښې دي؛ پاتې ۷۴ واحدونه لا نه دي منل شوي. د OLP-0609–0612 د ثبوت د طريقو وروستۍ برخې هم منل شوې سمون وړ مسودې دي؛ د استقرا څپرکے هم تر OLP-0619 پورې په سمون وړ متن کښې بشپړ دے؛ OLP-0620 د تاريخ برخه پيلوي. دا لا بشپړ کتاب نه دے او د انساني ژبپوه يا رياضيپوه د تصويب ادعا نه لري.

د لوستلو دپاره [اوسنے PDF](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.pdf) يا [EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-incompleteness.epub) پرانيزئ. د تېرې [محاسبه کېدنې PDF](readers/openlogic-ps-Arab-PK-cumulative-through-computability.pdf) او [EPUB](readers/openlogic-ps-Arab-PK-cumulative-through-computability.epub) په ګډون پخوانۍ نسخې هم ساتل شوې دي. د هر چاپ بشپړ توکي په [GitHub خپرونو](https://github.com/KokunoYumeto/openlogic-ps-Arab-PK/releases) کښې شته؛ د [همدې سمې شوې نسخې DOI](https://doi.org/10.5281/zenodo.22991939) او [Zenodo د همدې نسخو لړۍ](https://doi.org/10.5281/zenodo.22307197) هم وګورئ. د [ژباړو عمومي لړليک](https://github.com/KokunoYumeto/OpenLogic-translations) ته هم ورشئ. ## کتنه او د لوستونکي حدود

اتومات کتنه د اصلي فايلونو هشونه، د پاراګرافونو برابرون، چاپېريالونه، فارمولونه، اصطلاحي نښې، حوالې، يونيکوډ او پاتې عادي انګرېزي څېړي. معنايي کتنه د سرچينې او ژباړې د استدلال جهت، شرطونه، کمیت ټاکونکي او د ثبوت اړوندې بېلګې هم پرتله کوي. د پخوانۍ v0.7.0 د PDF ټول ۴۲۰ مخونه په انځوريز عمومي کتنه کښې وکتل شول؛ د v0.7.1 د سمون اړوند مخونه په بشپړ انځور کښې وکتل شول. د EPUB ۵۶ پراخې او د لوستونکي د پردې بېلګې په اتومات ډول وازمېيل شوې، او د نويو څپرکو ۱۴ بېلګې په سترګو وکتل شوې. EPUBCheck 5.4.0 هېڅ پيغام نۀ دے ورکړے. دا کتنې د انسان تصويب يا د هرې ژبنۍ تېروتنې نشتون نۀ ثابتوي.

اصلي انګرېزي تبصرې او پېژندونه د جوړښت د شواهدو دپاره پاتې دي. د اصلي فارمول دننه شخصي نوم `Ruth` يو مستند استثنا ده. د فارمولونو نثري متن پښتو دے. د `psOblique` نښه د پښتو لازمه نحوي بڼه جوړوي، خو د اصلي اصطلاح نښه او کلي ساتي. د v0.7.1 سرچينو ZIP د ۴۰۵ منل شويو مسودو فايلونه لري، خو لوستونکی لومړي ۳۲۱ واحدونه رانغاړي؛ تر `OLP-0648` پورې منل شوې مسودې شته؛ `OLP-0649` بل واحد دے.

## په Windows کښې بياجوړول

Python 3، XeLaTeX له `fontspec`، `amsmath/amsthm`، `bidi`، TikZ، `natbib`، `hyperref` او Amiri فونټ ته اړتيا ده. دا حکمونه د اوسني سمون وړ متن نوې مسوده جوړوي. د تاريخي خپرونې د عين بايټونو د بياجوړولو دپاره د هماغې خپرونې سرچينو ZIP وکاروئ:

```powershell
python tools/build_cumulative_reader.py --through-unit 648 --preamble ./tools/cumulative-reader-preamble-v107.tex --build-dir ./build/cumulative-through-c-functions-648
./tools/guard_tex.ps1 -Passes 4 -BibTeX -BuildDirectory ./build/cumulative-through-c-functions-648 -DocumentBases reader
python tools/check_translation.py
```

د PDF پايله `build/reader-v071/reader.pdf` ده. د نېغ خپاره شوي LaTeX متن د کره PDF د بياجوړولو دپاره يې `releases/reader.tex` ته کاپي او له هماغې لارې درې خوندي XeLaTeX پړاوونه وچلوئ:

```powershell
Copy-Item ./releases/02-openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.1.tex ./releases/reader.tex
./tools/guard_tex.ps1 -Passes 3 -BuildDirectory ./releases -DocumentBases reader
```

`guard_tex.ps1` د `Global\InterlanguageTeXSlotV1` ماشين‌سراسري قلف اخلي او د TeX د ټولو پړاوونو او لاګ کتنې تر پاې پورې ئې ساتي. د EPUB د ۳۱ شکلونو فهرست له همدې سمونې وړ سرچينو بيا جوړېږي:

```powershell
python tools/derive_cumulative_epub_figures.py --output ./build/v071-figures.json
python tools/render_cumulative_epub_figures.py --phase prepare --expected-figures 31 --inventory ./build/v071-figures.json --build-dir ./build/epub-v071-figures
$figureBases = 1..31 | ForEach-Object { 'figure-{0:D3}' -f $_ }
./tools/guard_tex.ps1 -Passes 1 -BuildDirectory ./build/epub-v071-figures -DocumentBases $figureBases
python tools/render_cumulative_epub_figures.py --phase convert --expected-figures 31 --inventory ./build/v071-figures.json --build-dir ./build/epub-v071-figures --output-dir ./build/epub-v071-svg
python tools/build_cumulative_epub.py --through-unit 321 --edition-version 0.7.1 --reference-map ./evidence/V071_EPUB_REFERENCE_MAP.json --build-dir ./build/epub-v071 --figures-dir ./build/epub-v071-svg
python tools/validate_cumulative_epub.py --epub ./build/epub-v071/openlogic-ps-Arab-PK-cumulative-through-incompleteness-v0.7.1.epub --build-record ./build/epub-v071/build-epub.json --alignment ./evidence/ALIGNMENT.jsonl --reference-map ./evidence/V071_EPUB_REFERENCE_MAP.json --output ./build/epub-v071/validation.json
```

د [مخونو کره لړ](evidence/V071_READER_OCCURRENCE_PAGES.json) د PDF له دوه يو شان AUX فايلونو جوړ شوے دے. د سرچينو ZIP کښې د EPUB د عددونو [منل شوې نقشه](evidence/V071_EPUB_REFERENCE_MAP.json)، جوړوونکي او د شکلونو سرچينې شته. د خپرونې د فايلونو هشونه د هغې له SHA-256 لړ سره پرتله کړئ.
